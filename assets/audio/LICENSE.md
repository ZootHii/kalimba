# Kalimba sample recordings

The WAV files in this directory are selected from the FreePats Kalimba sound bank, version 2019-07-23. The bank was created from recordings of a real kalimba and is released under the Creative Commons CC0 1.0 Public Domain Dedication.

- Source: https://freepats.zenvoid.org/Ethnic/kalimba.html
- License: https://creativecommons.org/publicdomain/zero/1.0/
- Included takes: `F3_01.wav`, `1_01.wav`, `2_01.wav`, `3_01.wav`, `4_01.wav`, `5_01.wav`, `6_01.wav`, and `7_01.wav`

The source bank's `Kalimba-20190723.sfz` defines the pitch center, fine tuning, and key range for each included take. Those values are reflected in the sample map in `app.js`.
